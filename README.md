# COVID-19 India Dashboard | Power BI

An interactive Power BI dashboard designed to analyze COVID-19 trends across India. The dashboard provides comprehensive insights into confirmed cases, recoveries, deaths, vaccination progress, and state-wise performance using interactive visualizations and dynamic filtering.

---

## Project Overview

This project transforms raw COVID-19 and vaccination datasets into an interactive business intelligence dashboard. The dashboard enables users to explore pandemic trends through multiple report pages, KPI cards, maps, charts, and slicers.

The project demonstrates data cleaning, ETL processing, data modeling, DAX calculations, and dashboard development using Microsoft Power BI.
